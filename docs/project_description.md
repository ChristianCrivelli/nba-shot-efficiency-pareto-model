# Project Description: NBA Shot Efficiency & Pareto Optimization Model1. 
In modern sports analytics, the "Moreyball" revolution heavily optimized basketball offenses by prioritizing high Expected Value ($EV$) shots: restricted area layups and 3-pointers. However, a pure $EV$ framework completely ignores variance (risk).This project develops a mathematical optimization model that frames shot selection as a multi-objective optimization problem. By treating the basketball court as an asset portfolio, the model calculates the exact "break-even" frontier where a team cannot increase their expected point return without simultaneously increasing the variance (risk) of missing the shot.
